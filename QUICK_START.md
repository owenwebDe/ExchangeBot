# 🚀 Quick Start - 5 Minutes to Running Bot

Get your Exchange Campaign Manager Bot running in 5 minutes!

## Prerequisites (2 minutes)

### 1. Get Bot Token
- Message [@BotFather](https://t.me/botfather) on Telegram
- Send: `/newbot`
- Follow prompts → **Copy your token**

### 2. Get Your User ID
- Message [@userinfobot](https://t.me/userinfobot) on Telegram
- Send: `/start`
- **Copy your ID** (the number shown)

## Installation (3 minutes)

### Step 1: Install Dependencies
```bash
npm install
```

### Step 2: Configure
Edit the `.env` file:
```env
BOT_TOKEN=your_token_here
ADMIN_IDS=your_user_id_here
BASE_URL=https://yourdomain.com
```

### Step 3: Start
```bash
npm start
```

**Done!** 🎉

## First Steps

### 1. Test the Bot
Message your bot on Telegram:
```
/start
```

### 2. Create Campaign
```
/newcampaign
```
Follow the wizard.

### 3. Generate Link
```
/newlink 1 @yourchannel
```

### 4. View Stats
```
/stats 1
```
